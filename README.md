 E-Commerce Customer Segmentation

 Overview
A Machine Learning project that segments e-commerce customers based on purchasing behavior using RFM (Recency, Frequency, Monetary) analysis.

 Tech Stack
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Jupyter Notebook
   Algorithms Used
- K-Means Clustering
- DBSCAN Clustering

 Key Features
- Data Cleaning and Preprocessing
- RFM Analysis
- Feature Scaling
- Elbow Method and Silhouette Score
- PCA and t-SNE Visualization
- Customer Segmentation and Profiling

 Results

| Algorithm | Silhouette Score |
|---|---:|
| K-Means | 0.3746 |
| DBSCAN | 0.1201 |

**K-Means performed better than DBSCAN.**
